# Studio content

The illustrated homepage is connected to `data/projects.ts`, `data/experience.ts`, `data/skills.ts`, and `lib/constants.ts`. Individual project pages remain available at `/projects/[slug]`.

There are 13 portfolio entries. The public GitHub audit found ten repositories including this portfolio; existing work without a separate public repository remains in the portfolio and links to Tatheer's profile. Irssa PSL was added from its public README. Jarvis and WiWave were updated to describe their current implementations. Readme snapshots are in `artifacts/github-readmes`.

Run `npm run studio:art` after changing project or education content to regenerate the illustrated exhibits. Run `npm run studio:styles` after changing the reference SCSS or office styles. Studio and Blog door drawings are generated by `scripts/build-door-art.cjs`.

Corridor viewing uses `useCorridorCamera.js`: cursor movement turns the view horizontally and vertically, dragging allows further rotation, the visible left/right buttons turn 90 degrees, and arrows/A/D turn incrementally. Scroll or W/S walks along the corridor; R/Home or Face forward resets the view. Damping uses elapsed time so camera motion remains consistent across frame rates. Room animations can take over and release the camera. The entrance renders before the hidden corridor is revealed, and its loading indicator waits for the entrance rather than background room downloads.

The corridor UI also offers a manual tour and a scripted auto tour. Auto tour steps are defined near the top of `useCorridorCamera.js`, and the visitor can pause, resume, replay, change speed, or return to manual exploration at any time. `DeveloperQuoteCard.jsx` rotates through short developer spotlights with a role and context note. The entrance garden renders two animated code ponds from `CodePonds.jsx`; the fish use language-inspired colors and labels for Python, Node.js, Rust, TypeScript, React, and Go.

The first corridor segment also hangs five physical developer spotlight posters from `DeveloperSpotlightWall.jsx`, alternating along the walls beside the certificate frames. Each poster carries the developer’s name, quote, role, and context note.

The Gallery background is now a generated technical architecture board (`gallery-architecture.webp`): its data-layer side explains users, cache, contracts, and a primary database, while its MCP side maps the user, MCP client, MCP server, tools, and resources. The previous house/city skyline layers were removed from `GalleryRoom.jsx`.

## Contact

The contact office offers WhatsApp and an email composer using the visitor's typed message. These handoffs open the visitor's messaging app; the visitor still sends the message there. WhatsApp uses the international number `923448901377` and email uses `mtatheer11@gmail.com`.

The existing `/api/contact` backend supports direct email delivery with Resend. Set `RESEND_API_KEY` and `CONTACT_EMAIL` in the server environment to enable the direct-send button. Its GET endpoint returns only a configuration boolean. Without those variables, the office uses an email composer. Failed delivery preserves the draft and offers WhatsApp and email links.

## Certificates
